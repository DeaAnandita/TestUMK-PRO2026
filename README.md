# Sistem Peminjaman Ruang

Aplikasi berbasis web untuk pengelolaan peminjaman ruang kampus.
Sistem digunakan oleh Admin dan Dosen untuk mengelola data ruang,
pengajuan peminjaman, serta approval penggunaan ruangan.


## Teknologi

- Laravel 9
- PHP 8
- MySQL
- Tailwind CSS
- Laravel Breeze Authentication
- PHPUnit


## Fitur

### Authentication
- Login Admin
- Login Dosen
- Role Middleware


### Manajemen Ruang

- CRUD data ruang
- Sinkronisasi data ruang melalui Web Service


### Peminjaman

- Pengajuan peminjaman ruang
- Approval / Reject Admin
- Validasi bentrok jadwal
- Riwayat peminjaman


### Dashboard

Admin:
- Total ruang
- Total peminjaman
- Status pengajuan


Dosen:
- Statistik pengajuan
- Riwayat peminjaman


### Search & Filter

- Pencarian ruang
- Filter gedung
- Filter status
- Filter tanggal
